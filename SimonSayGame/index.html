Simon Say Game

Press Any key(from keyboard) to Start the Game

RULES OF GAME:

  1. Press any key to start the game.
  2. The game flashes one random color.
  3. Click the same color that the game flashed.
  4. If your click is correct, the game moves to the next level.
  5. At each new level, the game adds one new color to the existing sequence.
  6. You must repeat the entire sequence in the correct order.
  7. If you click a wrong color or click in the wrong order, the game ends.
  8. Your score is the highest level you reached.
  9. Press any key again to restart after a game over.
