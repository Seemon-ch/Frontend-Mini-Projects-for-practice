# Profile Card Generator

A simple *Profile Card Generator* built using *HTML, CSS, and JavaScript*. This project demonstrates the use of *DOM manipulation* and *form handling*.

Users can fill in their details, such as:
* Profile Photo (URL)
* Name
* Occupation
* Description

When the *Submit* button is clicked, JavaScript dynamically creates a personalized profile card and displays it on the page without reloading the website.

# Features
* Dynamic DOM manipulation
* Form input handling
* Real-time profile card generation
