# Image Filter Editor

A simple and interactive *Image Filter Editor* built using *HTML, CSS, JavaScript, and the HTML5 Canvas API*. This project allows users to upload an image and apply multiple CSS-like filters in real time using sliders and download it.

## ✨ Features

*  Upload an image from your device
*  Real-time filter adjustments using sliders
*  Brightness control
*  Contrast adjustment
*  Saturation control
*  Hue Rotation
*  Blur effect
*  Grayscale filter
*  Sepia effect
*  Opacity adjustment
*  Invert colors
*  Instant preview using the HTML5 Canvas API
*  Responsive and clean user interface
* download your edited image
