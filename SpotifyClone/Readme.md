# Spotify Clone

A responsive *Spotify Web Player Clone* built using *HTML5* and *CSS3*. This project recreates the look and feel of Spotify's web interface, focusing on layout design, responsive styling, and modern UI components.

> Note: This is a front-end UI clone created for learning and practice purposes. It does not include music playback or backend functionality.
