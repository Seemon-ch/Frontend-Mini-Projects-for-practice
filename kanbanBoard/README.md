# Kanban Board

A simple and interactive *Kanban Board* built using *HTML, CSS, and JavaScript*. It helps users organize tasks by dragging them between different stages of completion.

# Features

*  Add new tasks using a modal form
*  Drag and drop tasks between columns
*  Three task stages: To Do, In Progress, Done
*  Delete tasks
* Live task count for each column
* Local Storage support (tasks remain after page refresh)
* Responsive and clean user interface

#  How It Works

1. Click *"Add Task"* to create a new task.
2. Enter the task title and description.
3. The task is added to the *To Do* column.
4. Drag and drop tasks between *To Do*, *In Progress*, and *Done*.
5. Delete tasks using the *Delete* button.
6. All tasks are automatically saved in the browser's Local Storage.
