# Willow Health

Willow Health is a simple healthcare website designed to provide a clean and welcoming interface for exploring primary care, mental wellness, and everyday health guidance.

## Features

- Clean and minimal healthcare-focused UI
- Responsive navigation bar
- Home, About, and Health Tips sections
- Healthcare service overview
- Interactive buttons using JavaScript
- Responsive and user-friendly layout
- Modern typography and healthcare-inspired design

## Technologies Used

- HTML5
- CSS3
- JavaScript
